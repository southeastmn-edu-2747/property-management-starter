# Course Evolution Roadmap

This repository is the starting point for the COMC 2747 Semester Application Project.

- Unit 1: connect and model persistent data with Entity Framework Core.
- Unit 2: implement CRUD, LINQ queries, services, DTOs, and data-driven API features.
- Unit 3: evolve the schema, add reliable operations, and build automated tests.
- Unit 4: automate testing with CI and diagnose data-access behavior; introduce containerized development resources.
- Unit 5: configure a cloud database, deploy the application, and complete final verification.

The Property Management domain is a teaching context. The course competencies are designed so another application domain can replace it in a future semester.
